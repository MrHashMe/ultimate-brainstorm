# Research

The research that shaped ultimate-brainstorm. None of it is needed to install or run the kit; it is here so you can
see where the design choices came from, check them, or redo the survey later.

| File | What it is |
|---|---|
| [DEEP_RESEARCH_PROMPT.md](DEEP_RESEARCH_PROMPT.md) | The research prompt: a reusable, copy-paste brief that turns a deep-research agent into a survey of the skills, plugins, MCP servers and frameworks that make Claude and Codex good brainstorming partners (scope, protocol, evidence rules and the scoring rubric; full and compact versions). |
| [BRAINSTORMING_TOOLS_REPORT.md](BRAINSTORMING_TOOLS_REPORT.md) | The ranked landscape: 393 brainstorming tools (skills, plugins, commands, methods) scored on an 11-criterion rubric, with the top entries re-checked by adversarial reviewers, plus how each one brainstorms, how to install it and what reviewers found. |
| [data/all_candidates.csv](data/all_candidates.csv) | Every candidate the sweep found (2,281 rows): check tier, triage priority, screening score, name, URL, kind, GitHub stars, last push, the search lanes that found it, and a one-line summary. |

The method built from this research, and why each stage looks the way it does, is in [docs/GUIDE.md](../docs/GUIDE.md).
The build spec for the kit itself is [docs/design/KIT_SPEC.md](../docs/design/KIT_SPEC.md).

Star counts, dates and rankings are a snapshot from September 2026; tools change quickly, so check a tool's own page
before relying on a number here.
